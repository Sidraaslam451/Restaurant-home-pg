# MR.CONE - Luxury Culinary & Fine Dining Landing Page

A premium, high-fidelity landing page for an elite dining experience. This project transforms a basic menu into a commercial-grade brand platform, featuring modern UI trends, fixed glassmorphic interactions, overlapping visual architectures, and smooth responsive layouts.

## 🚀 Key Features & Technical Architectures

- **Layered Design System:** Driven by globally declared CSS Custom Variables (`:root`) managing cohesive luxury tones like Gold Glow and Neon Orange.
- **Glassmorphic Navigation Module:** A fixed top header utilizing `backdrop-filter: blur()` for continuous context awareness during scrolling.
- **Overlapping Image Architecture:** An asymmetric layout in the "Our Story" section that utilizes CSS positioning and magnetic translate effects on hover.
- **Micro-Interactions & Hover Triggers:** Dynamic expanding underline systems and responsive status wraps on pricing tags when hovering over menu items.
- **Fluid Layout Engine:** Powered by CSS Grid and Flexbox with smart breakpoints, ensuring a seamless experience from massive desktops down to mobile viewports.

## 🛠️ Tech Stack Employed
- Semantic HTML5 Structures
- Advanced Vanilla CSS3 Core Style Layouts
- Font Awesome Vector Iconography (v6.5.1)
- Embedded High-Definition Gastronomy Assets (Unsplash)

## 📸 Core UI Sections Developed
1. **Interactive Utilities Fixed Navbar:** Sleek glass-panel top tracking header with action routing.
2. **Hero Impact Banner:** Full-screen promotional banner with crisp, high-contrast display typography (`Cinzel`).
3. **Our Story (Brand Legacy):** Asymmetric image gallery with modern typography grids and custom key indicators (`100% Premium`, `48H Maturation`).
4. **Signature Menu Grid:** Two-column split interface mapping detailed items, item descriptions, and reactive pricing tokens.
5. **Chef's Recommendations:** A clean product showcase section with card scaling shadows, visual tag banners, and ratings.
6. **Reservation Module:** Integrated minimalist table booking utility utilizing absolute vector placeholders inside input layers.
7. **Brand System Footer:** Three-column commercial layout containing locations, structured operating hours, and nested social networks.
